# app — настольное приложение (Qt Widgets, C++)

Графическая оболочка над конвейером. Написана на C++ с Qt Widgets, логику вызывает через встроенный интерпретатор Python.

## Архитектурная связка

Приложение на C++, а весь конвейер на Python. Мост — **pybind11 в режиме embed**: тот же инструмент, что связывает `mir` с `core`, только в обратном направлении.

```
  app (C++/Qt)
      │  pybind11::scoped_interpreter — C++ запускает Python
      ▼
  mir (Python)
      │  import mir_core — Python вызывает C++
      ▼
  core (C++/OpenCV)
```

Симметрия удобна на защите: один механизм связывания, применённый дважды, вместо зоопарка технологий.

**Главная опасность — GIL.** Питоновский конвейер работает минуты. Если вызвать его в потоке интерфейса, окно замёрзнет. Решение: `PipelineWorker` живёт в отдельном `QThread`, захватывает GIL только на время вызова Python и отпускает его между шагами. Прогресс возвращается через колбэк, который эмитит Qt-сигнал.

## `PythonBridge`

```cpp
class PythonBridge {
public:
    PythonBridge();   // pybind11::scoped_interpreter, добавление путей к mir/
    ~PythonBridge();

    // Полный разбор. Вызывается только из рабочего потока.
    PipelineResult run(const QString& source,
                       const PipelineConfig& config,
                       const std::function<void(QString, float)>& progress);

    // Пересборка из кэшированной транскрипции — быстро, без разбора видео
    PipelineResult rebuild(const PipelineConfig& config);

    bool isReady() const;         // модуль mir импортировался
    QString lastError() const;    // user_message из MirError, уже по-русски

private:
    py::scoped_interpreter guard_;
    py::object pipeline_;         // экземпляр mir.pipeline.Pipeline
    py::object cached_transcription_;
};
```

Перевод исключений: питоновские `MirError` ловятся, из них достаётся поле `user_message` (оно уже на русском — см. `mir/common/errors.py`) и показывается в `QMessageBox`. Технический traceback уходит в лог, пользователю не показывается.

## `PipelineWorker`

```cpp
class PipelineWorker : public QObject {
    Q_OBJECT
public slots:
    void process(const QString& source, const PipelineConfig& config);
    void cancel();

signals:
    void progressChanged(const QString& stage, float percent);
    void finished(const PipelineResult& result);
    void failed(const QString& userMessage);
};
```

Отмена реализуется через флаг, который проверяет питоновский колбэк прогресса: при выставленном флаге он бросает `CancelledError`. Прерывать поток силой нельзя — интерпретатор останется в неопределённом состоянии.

## `MainWindow`

Главный принцип интерфейса: **сценарий в три шага**. Вставил ссылку → нажал кнопку → получил PDF. Всё остальное убрано в настройки, чтобы не пугать музыканта техническими параметрами.

```
┌──────────────────────────────────────────────┐
│ Расшифровка нот                        ⚙ ?  │
├──────────────────────────────────────────────┤
│ Ссылка на видео:                             │
│ ┌─────────────────────────────┐ ┌──────────┐ │
│ │ https://youtube.com/...     │ │ Открыть… │ │
│ └─────────────────────────────┘ └──────────┘ │
│                    ┌──────────────────┐      │
│                    │  Распознать ноты │      │
│                    └──────────────────┘      │
├──────────────────────────────────────────────┤
│ Загрузка видео           ▓▓▓▓▓▓▓▓▓░ 90 %     │
│ Анализ видеоряда         ░░░░░░░░░░  0 %     │
│ Анализ звука             ░░░░░░░░░░  0 %     │
│ Сборка нот               ░░░░░░░░░░  0 %     │
├──────────────────────────────────────────────┤
│  [ предпросмотр нотного листа ]              │
│                                              │
│  Темп: 92 BPM   Тональность: ре мажор        │
│  Размер: 4/4    Совпадение каналов: 87 %     │
├──────────────────────────────────────────────┤
│  Сохранить PDF   Сохранить MIDI   MusicXML   │
└──────────────────────────────────────────────┘
```

Прогресс раздельный по этапам, а не одна полоска: пользователь видит, что происходит, и понимает, почему это занимает минуты.

Строка под предпросмотром — данные из `QualityReport`. «Совпадение каналов» показывает, насколько согласились видео и аудио: если цифра низкая, к результату стоит отнестись критически.

## `SettingsDialog`

| Параметр | Тип | Комментарий |
|---|---|---|
| Прокси | строка | обязателен из-за блокировки YouTube |
| Использовать GPU | флажок | автоопределение, но можно отключить |
| Жёсткость квантизации | ползунок 0–100 | самая полезная ручка, влияет сильнее всего |
| Темп (BPM) | число / авто | переопределение при ошибке beat-tracker |
| Тональность | список / авто | 24 варианта |
| Тактовый размер | список / авто | |
| Путь к MuseScore | путь | если не нашёлся автоматически |
| Папка кэша | путь | + кнопка «Очистить» |

Изменение любого музыкального параметра запускает `rebuild`, а не полный `run`: ноты пересобираются за секунды из кэшированной транскрипции.

## `PdfPreview`

Отрисовка страниц PDF в `QImage` и прокрутка. Варианты реализации:

- **Poppler-Qt6** — нативно, без Python, но лишняя зависимость в сборке;
- через питоновский **PyMuPDF** и передачу растра в C++ — проще, интерпретатор уже поднят.

Второй вариант предпочтителен, если PyMuPDF уже нужен где-то ещё; иначе Poppler чище.

## Локализация (`i18n/`)

Штатный механизм Qt: все строки в коде оборачиваются в `tr()`, переводы собираются `lupdate` в `mir_ru.ts`, компилируются `lrelease` в `.qm`.

Отдельная задача — **русская музыкальная терминология**. Ноты выводятся как до/ре/ми, а не C/D/E; тональности — «ре мажор», а не «D major»; длительности — «четвертная», «восьмая». Для этого нужен словарь-конвертер, работающий над тем, что отдаёт music21 (там всё по-английски):

```cpp
QString localizeKeyName(const QString& musicxmlKey);   // "D major" → "ре мажор"
QString localizePitchName(int midiPitch);              // 62 → "ре"
QString localizeDuration(const QString& type);         // "quarter" → "четвертная"
```

Это не косметика, а прямое выполнение цели работы: аналоги англоязычны, локализация — заявленная новизна.

Небольшая ремарка: оставим возможность пользователю выбрать раскладку нотной клавиатуры.

## Сборка

```bash
cmake -B build -S . -DCMAKE_PREFIX_PATH=/path/to/Qt6
cmake --build build --config Release
```

Зависимости: Qt 6.5+, Python 3.10+ с dev-заголовками, pybind11.

Для распространения под Windows: `windeployqt` собирает Qt-библиотеки, Python-окружение кладётся рядом как embeddable-дистрибутив. Веса модели транскрипции (~170 МБ) в установщик не входят — скачиваются при первом запуске.
