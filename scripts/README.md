# scripts — командные утилиты

Всё, что запускается из терминала помимо основного приложения: отладка, эксперименты, сборка. Тонкие обёртки над `mir` — никакой логики здесь быть не должно.

Отдельная папка нужна по практической причине: во время разработки GUI ещё нет, а конвейер гонять надо. И для экспериментальной главы прогоны удобнее делать скриптом, а не кликами.

## Файлы

```
scripts/
├── transcribe.py    основной CLI: ссылка → ноты
├── evaluate.py      подсчёт метрик на тестовом наборе
├── ablation.py      эксперименты по вкладу каналов
├── make_dataset.py  генерация синтетических роликов
├── benchmark.py     замеры производительности
└── debug_frames.py  выгрузка кадров с разметкой
```

## `transcribe.py`

```bash
python scripts/transcribe.py "https://youtube.com/watch?v=..." -o ./output
python scripts/transcribe.py ./local.mp4 --bpm 92 --key "D major" --quantize 0.5
python scripts/transcribe.py ./local.mp4 --proxy socks5://127.0.0.1:1080 --no-gpu
```

```python
# Основные аргументы
--output, -o        папка результата (по умолчанию ./output)
--bpm               переопределить темп
--key               переопределить тональность
--time-signature    переопределить размер
--quantize          жёсткость квантизации 0..1
--proxy             прокси для yt-dlp
--no-gpu            принудительно на CPU
--formats           midi,musicxml,pdf (по умолчанию все)
--dump-intermediate сохранить промежуточные данные для отладки
--verbose, -v       подробный лог
```

Тот же самый `Pipeline`, что использует GUI. Если результаты CLI и приложения расходятся — это баг, а не особенность.

## `evaluate.py`

```bash
python scripts/evaluate.py --videos data/videos --gt data/ground_truth -o results.csv
```

Прогоняет весь набор, считает метрики (см. `tests/README.md`), пишет CSV — готовую таблицу для диплома:

```csv
video,category,note_f1,onset_mae_ms,key_correct,tempo_error_pct,hand_accuracy,elapsed_sec
synthesia_1080p60_chopin,baseline,0.94,18.3,True,0.4,0.97,142
cropped_5oct_480p,cropped,0.81,31.7,True,1.2,0.89,96
```

## `ablation.py`

Ключевой скрипт для доказательства новизны. Прогоняет один набор в четырёх режимах и сравнивает:

```bash
python scripts/ablation.py --videos data/videos --gt data/ground_truth
```

| Режим | Что проверяет |
|---|---|
| `video-only` | Только CV-канал — как работают существующие видео-парсеры |
| `audio-only` | Только нейросеть — как работают аудио-транскрипторы |
| `fusion` | Оба канала со слиянием — предлагаемый метод |
| `fusion-no-align` | Слияние без компенсации рассинхрона — вклад выравнивания |

Если `fusion` не выигрывает у обоих одиночных режимов, заявленная новизна не подтверждается. Лучше узнать это заранее, а не на защите.

Результат — таблица и график, идут прямо в экспериментальную главу.

## `make_dataset.py`

```bash
python scripts/make_dataset.py --midi-dir ./midi --out data/synthetic --count 50 \
    --vary fps,resolution,bitrate,color_scheme,crop
```

Генерирует синтетические ролики из набора MIDI (см. `tests/fixtures/synth.py`). Позволяет получить сотни примеров с точным эталоном, варьируя условия. Отсюда берутся данные для графиков «зависимость точности от fps / разрешения / битрейта».

## `benchmark.py`

```bash
python scripts/benchmark.py --video data/videos/test.mp4 --repeat 3
```

Замеряет время по этапам и сравнивает C++ реализацию с Python-фолбэком:

```
Этап                     C++       Python    Ускорение
─────────────────────────────────────────────────────
Детекция клавиатуры      0.8 c     4.2 c      5.3×
Трекинг клавиш          12.4 c    186.0 c     15.0×
Трекинг блоков          18.1 c    240.5 c     13.3×
```

Эта таблица — прямое обоснование выбора C++ в дипломной работе. Без неё вопрос «зачем вам C++, всё же есть в Python?» останется без ответа.

## `debug_frames.py`

```bash
python scripts/debug_frames.py video.mp4 --times 10.0,25.5,60.0 --out ./frames
```

Сохраняет кадры с наложенной разметкой клавиатуры и рамками блоков. Первое, что нужно запустить, когда распознавание даёт мусор: обычно сразу видно, что разметка съехала или блоки не детектируются.

Отсюда же берутся иллюстрации для пояснительной записки.
